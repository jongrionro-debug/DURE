# Dure Docs

이 폴더는 현재 `dure` 제품을 이해하고 운영하는 데 필요한 문서만 둔다.

## 현재 기준 문서

- `PRD.md`: 제품 요구사항과 핵심 사용자 흐름
- `ARCHITECTURE.md`: 기술 구조와 도메인 설계 원칙
- `ADR.md`: 주요 기술/제품 의사결정 기록
- `ENV_SETUP.md`: 로컬 환경과 외부 서비스 설정
- `SYSTEM_REPORT.md`: 현재 구현 상태와 시스템 동작 요약
- `UI_GUIDE.md`: UI 방향과 화면 작성 기준
- `CODEBASE_GRAY_BOXES.md`: 코드베이스를 행동 단위로 읽기 위한 지도
- `REPORT_ASSISTANT_PRD.md`: 다음 단계 보고서 작성 보조 기능 요구사항

## 보관 정책

완료된 구현 이력, 외부 repo성 참고 자료, 일회성 handoff 산출물은 이 폴더에 두지 않는다. 필요한 경우 repo 밖 보관 폴더에 분리한다.
